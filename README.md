# 🍳 Cocina Básica · Fichas técnicas

Sitio web estático con las 41 fichas técnicas de la asignatura Cocina Básica (PGG1101), Escuela de Gastronomía Duoc UC, sede San Andrés de Concepción. Página desarrollada por Claudia Gutierrez Poza.

## Contenido
- **Portada** (`index.html`): presentación, enlaces a los sitios de Salsas y Panadería, menú por áreas, recetario con filtros y buscador, explorador de puntos de cocción, glosario y contador de visitas.
- **8 áreas** (`areas/`): Ensaladas y entradas frías, Salsas, Fondos y ayudas de cocina, Sopas, cremas y potajes, Pastas frescas, Carnes y aves, Pescados y mariscos, Guarniciones.
- **41 recetas** (`recetas/`): productos agrupados con selector de porciones, proceso por etapas con progreso, notas y puntos críticos.

## Enlaces a Salsas y Panadería
Abre `assets/js/enlaces.js` y pega la dirección de cada sitio entre las comillas. Mientras un enlace esté vacío, el botón muestra "¡Muy pronto!".

## Publicar en GitHub Pages
1. Crea un repositorio nuevo (por ejemplo `cocina-basica-fichas`).
2. Sube **el contenido de esta carpeta** a la raíz del repositorio (*Add file → Upload files*).
3. Ve a **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En uno o dos minutos el sitio estará en `https://TU-USUARIO.github.io/cocina-basica-fichas/`.
